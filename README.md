# AJAYNXT Biomech V2

A GitHub Pages-ready biomechanical medical-technology concept website.

## Included

- 7 complete hero styles
- realistic stock photography
- no website screenshots used as sections
- automatic style rotation every 60 seconds
- manual style selector
- dark and light modes
- visible color library
- color search and HEX input
- color picker and color lock
- visible text library and text lock
- font selector and font lock
- responsive motion
- product tabs and specifications modal
- patient, clinician, research and distributor routes
- WhatsApp enquiry form
- CNAME for `biomech.ajaynxt.com`

## Photo note

The website uses individual stock and public-domain images by URL. It does not use pasted website screenshots.

Before a commercial client launch:
- replace imagery with approved client photography where available
- verify all manufacturer specifications and medical claims
- replace concept product names and contact details
- add the client's privacy policy, terms and regulatory information
