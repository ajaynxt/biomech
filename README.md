# AJAYNXT Biomech Showcase

A GitHub Pages-ready concept website containing seven switchable biotech and bionics styles.

## Included

- 7 separate style directions
- automatic 60-second style rotation
- manual style navigation
- visible color library
- visible text library
- color search and HEX input
- color picker and lock
- text selection and lock
- font selection and lock
- light and dark modes
- original SVG/CSS biomechanical visuals
- no pasted website screenshots
- responsive motion
- WhatsApp consultation form
- reduced-motion support
